\## Setup Instructions



\### Prerequisites

\- Python 3.10+

\- UV package manager

\- Git



\### Installation

1\. Clone this repository:

&#x20;  git clone https://github.com/<your-username>/business-analytics-portfolio.git

&#x20;  cd business-analytics-portfolio



2\. Set up environment:

&#x20;  uv sync



3\. Run anything inside the project environment:

&#x20;  uv run python --version



UV resolves the environment for each command, so there is no separate

activation step needed.



\## Usage

\- Analysis: uv run jupyter notebook notebooks/

\- Tests: uv run pytest



\## Project Structure

\- src/ — source code (data\_pipeline, analysis, modeling, dashboard)

\- tests/ — unit tests
